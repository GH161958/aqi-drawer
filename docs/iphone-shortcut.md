# iPhone「扔给爸爸」快捷指令

## 分享菜单设置

1. 新建快捷指令并命名为“扔给爸爸”；
2. 打开快捷指令详情，启用“在共享表单中显示”；
3. 接收类型选择 URL、文本、图像及需要支持的媒体类型；
4. “如果没有输入”建议选择停止并提示，不要自动读取剪贴板中的服务地址。

## 请求动作

添加“获取 URL 内容”：

- URL：你的私密 `https://host/drop/<secret>`；
- 方法：`POST`；
- 请求体：JSON；
- `share`：选择“快捷指令输入”；
- `sourceApp`：填写 `iPhone 分享菜单`。

随后添加“显示结果”，内容选择上一动作“获取 URL 内容”的结果。

V2.3 起私密 Drop 默认返回短文本。不要再添加“获取词典值 message”；只有明确使用 `?response=json` 时才需要解析 JSON。

## 使用

在淘宝、小红书、Safari、Chrome 等 App 中打开分享菜单，选择“扔给爸爸”。若某个 App 使用自己的第一层分享面板，先点“复制链接”，再从系统分享菜单或浏览器运行快捷指令。

## 安全

- 不要在截图、录屏、README 或社交媒体里展示完整 Drop URL；
- 不要把服务地址当作普通分享内容测试；
- 正式部署后若地址曾公开，立刻更换 `C_POCKET_DROP_SECRET`；
- 电脑离线时，本地服务无法接收；要实现全天接收，需要常驻服务器或家中常开设备。
