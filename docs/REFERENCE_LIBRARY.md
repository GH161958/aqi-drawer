# Aqi Drawer Reference Garden / 参考花圃

> Borrow the language, not the skin.
> Borrow the grammar, not the composition.
> 先找气质 → 再找机制 → 最后找零件。

参考不是复刻任务。拆解时先问：谁是视觉主角，什么在前、什么藏在后、哪些边缘露出、什么允许错位、什么必须稳定、信息怎样分层，以及 storage 与展开状态分别显示什么。真实内容负责颜色和生活痕迹，装饰不能代替内容。

Last reviewed: 2026-08-16

## 网页灵感与实现常用网站推荐手册

- **REFERENCE**：用户提供的现有设计参考 PDF
- **SOURCE / LINK**：项目外部参考资料
- **ROLE**：总体参考方法论
- **BORROW**：先找气质，再找机制，最后找零件；每屏一个视觉主角；避免效果堆叠
- **DO NOT COPY**：任何单一网站的完整视觉皮肤
- **APPLIES TO**：整个 Aqi Drawer
- **NOTES**：借设计语言，不复制皮肤

## Catalog / Library Card Stacks

- **REFERENCE**：catalog cards / vintage library cards
- **SOURCE / LINK**：用户提供的参考图片
- **ROLE**：Open Drawer 的 orderly mess
- **BORROW**：不同宽度、水平错位、轻微叠压、露边、统一阅读方向；优先顺序为 offset → edge reveal → overlap → width variation → tiny rotation
- **DO NOT COPY**：古董滤镜、grunge、假污渍、scrapbook 构图
- **APPLIES TO**：Open Drawer composition
- **NOTES**：变化稳定地由 item id 决定，不使用 random

## Spatial

- **REFERENCE**：Spatial
- **SOURCE / LINK**：[get-spatial.com](https://www.get-spatial.com/)
- **ROLE**：object differentiation、organic stacks、invisible controls 的交互/物件模型参考
